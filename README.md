# CleanSub (starter)

CleanSub is a local-first PWA that extracts recurring payments from bank/credit card CSV exports and lists subscriptions with quick cancellation guidance.

Quick start (local):
1. cd cleansub
2. npm install
3. npm run dev
4. Open http://localhost:5173

Notes:
- Parsing is client-side by default (no data leaves your machine).
- Use sample CSV files or an export from your bank.
